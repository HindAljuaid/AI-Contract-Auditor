They are kept separate from `validation/hospital_1/`, which contains the labeled Hospital 1 benchmark and validation evidence.

## Folder contents

Each hospital folder contains:

- `hospital_X_contract_rules.json` — structured contract rules used by the audit.
- `hospital_X_submission.csv` — final invoice-level audit output.
- `hospital_X_review_queue.csv` — invoices requiring manual review.
- `hospital_X_service_mapping.csv` — service-description mapping evidence.
- `hospital_X_line_audit.csv` — line-level deterministic audit evidence.

## Notes

- Hospitals 2–5 are unlabeled challenge datasets, so these files are model/system outputs rather than ground-truth validation results.
- Hospital 1 validation evidence should remain under `validation/hospital_1/` because that dataset has labels and is used to measure precision/recall.
- These outputs are reproducibility artifacts from the public demo and can be regenerated by analyzing the corresponding contract and running the audit.
