# Hospital 1 Validation Evidence

This folder preserves the original Hospital 1 development/validation work separately from the app's normal submission output.

Hospital 1 is the labeled development dataset, so it is used to measure the deterministic audit rules against known ground truth.

## Validation result

- Perfect categories: **18/18**
- Mean precision: **1.000**
- Mean recall: **1.000**
- Mean F1: **1.000**
- Total true positives: **105**
- Total false positives: **0**
- Total false negatives: **0**

## Files

- `hospital_1_validation_development.ipynb` — original notebook used while developing and validating the Hospital 1 rule logic. It includes the printed validation output.
- `hospital_1_validation_reference.py` — standalone Python version extracted from the notebook.
- `outputs/hospital_1_category_evaluation.csv` — per-category precision, recall, F1, TP, FP, and FN.
- `outputs/hospital_1_category_predictions.csv` — predicted error categories for each Hospital 1 invoice.
- `outputs/hospital_1_line_mapping.csv` — line-level service mapping used by the validator.

## Why this is separate from the app submission

The Streamlit demo uses the general auditing workflow and can generate a normal submission CSV. That file is an application output.

The files in this folder are **validation evidence** for the labeled Hospital 1 benchmark. Keeping them separate prevents the benchmark evidence from being confused with a later submission generated by the demo.

## Reproduce locally

From the repository root:

```bash
python validation/hospital_1/hospital_1_validation_reference.py \
  --data-dir exercise_data/insurance_auditing-main \
  --output-dir validation/hospital_1/outputs
```

The script regenerates the three CSV files in `validation/hospital_1/outputs/`.
